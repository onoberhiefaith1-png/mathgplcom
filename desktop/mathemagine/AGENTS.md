- The desktop Mathemagine (platform) app is a thin Electron shell over https://mathgpl.com/ — the main website, not offline Academia (`desktop/academia`). It needs internet and registers no worker of its own.
- Every identifier differs from `desktop/academia` (package `mathemagine-platform`, AppUserModelId `com.mathgpl.mathemagine.platform`, data folder `Mathemagine Platform`, install folder, uninstall key `MathemaginePlatform`, `Mathemagine Platform.lnk`), because Academia's desktop app keeps its earlier plain `Mathemagine` install folder, uninstall key and data folder, and its installers delete `Mathemagine.lnk` and close `Mathemagine.exe`; reusing those would overwrite, close or unshortcut one app from the other.
- Build like Academia (`@electron/packager . "Mathemagine Platform"` so the exe is `Mathemagine Platform.exe` — Academia's installer force-closes any `Mathemagine.exe` — then nix `makensis`); updates are announced from `public/desktop/mathemagine-latest.json`, never self-installed. No binaries are published yet.
- A manual Update unregisters the site worker, drops HTML/JS caches, and — via `preload.cjs` / `mathgplDesktop.clearWebCache` — clears this window's HTTP cache and service-worker registrations without signing the user out or deleting lesson caches. The JS path arrives by publishing the site; the IPC bridge needs a new installer (package.json 1.0.1). Do not bump the Mathemagine latest.json until that installer is uploaded.
