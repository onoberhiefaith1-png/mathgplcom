- The desktop Mathemagine (platform) app is a thin Electron shell over https://mathgpl.com/ — the main website, not offline Academia (`desktop/academia`). It needs internet and registers no worker of its own.
- Every identifier differs from `desktop/academia` (package `mathemagine-platform`, AppUserModelId `com.mathgpl.mathemagine.platform`, data folder `Mathemagine Platform`, install folder, uninstall key `MathemaginePlatform`, `Mathemagine Platform.lnk`), because Academia's desktop app already uses the plain `Mathemagine` names; reusing them would overwrite or uninstall Academia.
- Build like Academia (`@electron/packager . "Mathemagine Platform"` so the exe is `Mathemagine Platform.exe` — Academia's installer force-closes any `Mathemagine.exe` — then nix `makensis`); updates are announced from `public/desktop/mathemagine-latest.json`, never self-installed. No binaries are published yet.
