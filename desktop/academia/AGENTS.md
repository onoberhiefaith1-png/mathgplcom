- The desktop Academia app (published as "Mathemagine" up to 1.0.1) is a thin Electron shell that loads only https://mathgpl.com/academia-app and relies on Academia's own offline worker and IndexedDB, so it never forks Academia code; content and UI updates arrive by publishing the site, and other links open in the system browser.
- Windows ships as a per-user NSIS installer (`installer.nsi`, built with nix `makensis` over `@electron/packager` output) because electron-builder fails in the sandbox; Mac ships as unsigned zips until Apple signing exists.
- User data lives in a fixed `Mathemagine` app-data folder (old profiles migrate once); that folder, the install folder `Programs\Mathemagine`, the uninstall key `Mathemagine` and AppUserModelId `com.mathgpl.mathemagine` keep the earlier name so upgrades replace the install in place; only visible names say Academia, so upgrades/reinstalls keep progress; the uninstaller keeps it by default.
- Shell updates are announced, never self-installed: the app compares its version to `public/desktop/latest.json`; bump that file, `package.json` and `src/lib/offline/releases.ts` together when re-uploading builds.
