# Move large Game files to Lovable file hosting

## Goal
Make publishing fast and reliable by taking about 776 MB of game music, artwork, characters and effects out of the project. Games must look and sound the same online. Offline Academia must stay fast and keep working.

## What moves
- Everything under `public/assets/` (audio, environment, rewards, ui, characters, effects, backgrounds, obstacles, animations): about 960 files.

## What stays in the project (small, needed offline on first open)
- `public/offline-game/` (castle and writing-surface frames, 581 KB)
- App icons, fonts, the web manifest, favicon, the Android APK and robots.txt

## Steps
1. Upload each file under `public/assets/` to file hosting with `lovable-assets create`.
2. Generate one lookup file that maps each old address (for example `/assets/audio/music/x.mp3`) to its new hosted address.
3. Add one helper, `publicAsset(path)`, that returns the hosted address for an old address and leaves anything else unchanged.
4. Route every reference through that helper: the 24 source files that name `/assets/...` directly, plus places where saved Games, rooms and rewards read file addresses from the database. Saved Games already in the database keep working without any data change.
5. Delete the original files from `public/assets/`.
6. Offline: the offline worker already saves hosted files cache-first, so offline Academia keeps any Game media it has saved. Its "Get ready" list will use the new addresses.
7. Verify: run the typecheck and tests, check for any remaining `/assets/` file addresses, load the Game and Academia in the browser, and confirm music and images come from hosting.

## Technical details
- Lookup file: `src/lib/assets/publicAssetMap.json`, generated by a script from the CLI outputs. No addresses are typed by hand.
- Helper: `src/lib/assets/publicAsset.ts`. It is applied at render and audio-load points such as ImagineBackground, sound players, reward and character pickers, and the asset library pages.
- Page links such as `/assets/${slug}` are page addresses, not files, and are left unchanged.
- Add a rule to `AGENTS.md`: Game media lives on file hosting and is reached only through `publicAsset()`.
- Afterwards the project's saved history still contains the old files. New publishes copy the current files, so they should be much smaller, but this is not guaranteed until a publish succeeds.
