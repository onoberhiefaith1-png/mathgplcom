# A "View exercise" path on the Exercise Card

Right now the Exercise Card in the Course Builder shows its name, topic, subtopic, total marks and pass mark — but there is no way in. This adds that door, straight from the card the teacher is editing, with no class needed.

## What the teacher gets

On every Exercise Card, under the marks fields:

- A live summary read from the questions actually linked to the card: **5 questions · 34 marks** (marks are the linked questions' own marks added together, so the number is always true even if the typed Total marks field disagrees).
- A **View exercise** button.

Pressing it opens the exercise's own page listing every question in card order — Question 1, Question 2, … with each question's marks and a "Video" badge where a teaching video already exists.

Picking a question opens the normal teacher Test Smartboard for that question, unchanged: all existing testing features, Floating Numbers, Present, evaluation and marking. The one addition is the **Add Video** icon already built — three-view Smartboard / Split / Video, one continuous upload, one checkpoint per mathematical line.

The card's typed **Total marks** field stays editable and untouched; the summary is shown next to it as the real figure.
