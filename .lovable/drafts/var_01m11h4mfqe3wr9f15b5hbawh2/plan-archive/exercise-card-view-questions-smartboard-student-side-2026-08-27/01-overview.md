# Exercise Card → View Questions → Smartboard (student side)

An Exercise Card in a course already links real Lesson Note questions. What is missing is the student's way in. This adds it, using the solving board students already use for assignments — no new marking engine, no teacher tools, no Course Builder redesign.

## What the student gets

- Each Exercise Card in the Student View gains a **View Questions** action (with the question count).
- It opens a simple **question list** for that card: Question 1, Question 2, Question 3…, each with its marks and the student's own result so far (Not started / In progress / Score).
- Selecting a question opens it on the Smartboard, scoped to that one question, with the normal solving interface and the automatic real-time marking students already have.
- Finishing returns to the question list, where the new mark appears, and the card shows earned/total against its pass mark.
- The student never sees the Testing Ground, the Evaluation panel, or any teacher control — those live only on teacher pages and are not rendered on this route.

## What the teacher gets

Nothing changes. The Testing Ground, the exercise question picker, and the teacher evaluation environment stay exactly as they are. Inside the Course Builder preview the Exercise Card shows the same **View Questions** affordance but inert, so the teacher sees what the student will see.
