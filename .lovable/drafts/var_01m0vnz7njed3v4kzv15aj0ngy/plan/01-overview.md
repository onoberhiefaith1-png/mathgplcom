# Symbols quick-access — final category order

Rebuild the Symbols button in the Lesson Note ribbon as a docked right-hand panel (same behaviour as the Matrix and Emoji panels: it shares the page width, never covers the note) containing only the notation teachers reach for while writing.

Rules that hold everywhere in this panel:

- Click a plain symbol → inserted at the cursor instantly, no confirmation, panel stays open.
- Click a structure (fraction, root, power, sin θ =, ∫ …) → the real editable object is inserted and the caret lands in the first empty cell, so typing continues immediately. Never raw code on the page.
- No new page, no dialog, no Matrix — Matrix keeps its own separate palette.
- The full Asset Library stays untouched for everything else.

Category order shown top to bottom, exactly as requested:

1. Core
2. Greek letters
3. Algebra
4. Number & fraction
5. Plane trigonometry
6. Geometry
7. Coordinate geometry
8. Statistics & probability
9. Calculus
10. Sets
11. Logarithms & exponentials

Each category is a compact band of chips, one screen, scrollable, with a small search box at the top that filters across all bands without changing their order.
