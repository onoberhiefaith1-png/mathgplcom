# Every question gets its own Solution session

## What you get

1. **New lesson notes** are always built as Question session → Solution session, one pair at a time: Classwork 1 → Solution 1 → Classwork 2 → Solution 2 …, and the same for Examples, Exercises, Homework and Assessment. Introduction, Explanation and Summary never get a Solution.
2. **A "Restructure lesson" action** on any open note (well organised, messy, or with every heading deleted). It reads the whole note, works out what each part is, and rebuilds it into the correct session order.
3. **Nothing leaves unpaired.** Before a note is called Smartboard-ready, a final check rejects "all questions then all solutions", "question and solution in one session", or a question with no Solution session — and fixes it.
4. **The Smartboard steps Question → Solution** as two separate screens, so the teacher can show the question first and move on to its solution.

## How Restructure behaves

- **Understand first.** It finds where each question starts and ends and where each solution starts and ends, even with no "Question" or "Solution" label (for example, "Add all the values… 35 ÷ 4 = 8.75" is recognised as the solution to the question above it).
- **Keep what exists.** A solution found anywhere in the note is matched to its own question and moved into that question's Solution session. It is not rewritten from scratch.
- **Improve, don't replace.** Wording, grammar and layout are tidied, but numbers, the method, the answer and the difficulty stay the same. The question-lock rule still applies: the question itself is never swapped for a different one.
- **Fill the gaps.** If a question has no solution anywhere, a Solution session is created and the maths engine writes it, following the house style (one step per line). If the maths engine can't produce a verified solution, the Solution session is still created, clearly marked "needs solution", and listed for you. It is never dropped silently.
- **Logical numbering.** Solution numbers always match their question within each activity (Homework 3 → Solution 3).
- **Safe to undo.** A restore point is saved before any restructure, and you see a short summary of what moved, what was tidied and what was newly written before you accept it.
