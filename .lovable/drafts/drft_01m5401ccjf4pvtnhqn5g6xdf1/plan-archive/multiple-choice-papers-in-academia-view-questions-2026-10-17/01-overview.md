# Multiple-Choice Papers in Academia ("View Questions")

## What stays exactly the same
- Academia navigation: Class → Subject card → Topics → Subtopics → Sessions. No new buttons beside the subject.
- Practice, Play, Floating Numbers, Game, Adventure, Lesson Notes, Assignments: untouched.

## The one new entry point
Each Subject card (Mathematics, Physics…) gets a small **⋯** in its top-right corner. Tapping it opens a dropdown with **View Questions**. The ⋯ stops the tap from reaching the card, so it never opens Topics by accident. Same on the web Academia and in Mathemagine.

## Connected workflow (built in this round)
1. **Teacher writes the paper as a Lesson Note** (one note = one paper, e.g. "JAMB 2018 Mathematics"), in the normal style:
   `Question 1` / question text (maths, diagrams allowed) / `A. … B. … C. … D. …` / `Correct Answer: B`.
2. **Convert to Multiple-Choice** (lesson-note ⋯ menu): a 3-step dialog — choose note → preview (every question numbered, options and answer detected, problems flagged in amber, e.g. "Question 14 has no answer") → save. Re-converting the same note updates the paper, never duplicates it.
3. **Assign to Academia subject**: in the same dialog, pick Class → Subject (school workspaces only; teachers only for their assigned Subjects, same rule as today).
4. **Student: ⋯ → View Questions** → a clean list of papers for that Subject (title, number of questions, best score, **Start**).
5. **Exam page**: question on the left/top, A–D options as large tappable rows, number grid (answered = filled, current = outlined), Previous / Next, Submit (confirms if any unanswered).
6. **Results**: score (e.g. 69/100, 69%), three clickable tiles — **Correct**, **Incorrect**, **Unanswered**. Each opens a filtered review that keeps the original question number ("Question 7 · 3 of 26 incorrect"): your wrong pick in red, correct answer in blue. Submitted answers cannot be changed; **Retry** starts a fresh attempt.
7. **Saved history**: every attempt is kept; the paper list shows best score and last attempt.
8. **Mathemagine offline**: papers travel in the existing offline Academia pack, are marked on the device (no internet, no AI), and attempts queue for sync exactly like current activities.

## Visual direction
Matches today's Mathemagine: white/light-grey surfaces, soft cards, rounded corners, subject colour as the only accent, dark readable ink, the same maths renderer as Lesson Notes. No dark-blue backgrounds. Comfortable on a 428px phone and on the desktop app.
