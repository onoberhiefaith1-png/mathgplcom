# Reports — two lenses, one data source

The Reports page becomes a two-mode screen. Nothing is removed: today's bar chart and trend chart stay exactly as they are and become the **Class Overview** mode. A new, much more detailed **Individual Student** mode is added and becomes the first thing a teacher sees.

Both modes read the same live assessment records, so any number in the class view can be traced down to the student who produced it.

## What the teacher sees

- **Top of page:** a single switch — `Individual Student | Class Overview`. Individual Student is selected by default.
- **Individual Student:** a student picker, four summary cards (Assessments, Marks Earned, Assessment Completion, Average Mark), a filterable assessment table, a Topic → Subtopic performance breakdown, and the performance graph over time.
- **Class Overview:** the current report — class summary cards, the existing bar chart, trend chart and report settings — plus Topic → Subtopic drill-down that ends on a student, which opens that student in Individual Student mode.
- **Floating Numbers** activities are reported as marks earned out of marks available with a completion bar. No Pass / Fail / Failed wording anywhere in Reports.
