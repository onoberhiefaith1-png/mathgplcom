# Reports — two lenses, one data source

The Reports page becomes a two-mode screen matching the mockup. Nothing is removed: today's bar chart and trend chart stay and live inside the **Class Overview** mode. A new, detailed **Individual Student** mode is added and becomes the first thing a teacher sees.

Both modes read the same live assessment records, so any number in the class view can be traced down to the student who produced it.

## What the teacher sees

- **Header:** back link, "Reports / Student assessments and class performance", the `Individual Student | Class Overview` switch, filter and settings icons. Individual Student is selected by default.
- **Individual Student panel:** student picker + class name, four summary cards (Assessments, Marks Earned, Assessment Performance, Average Score), an Assessment Activities table (#, Assessment, Type, Topic, Subtopic, Marks, Earned, Completion) with All Types / All Topics / All Time filters, an Assessment Detail card for the selected row (including Floating Numbers construction completion bar), Progress Over Time graph, and a Recent Activity list.
- **Class Overview panel:** class summary cards (Students, Assessments, Marks Available, Class Performance), Class Performance by Topic bars, Class Performance by Subtopic bars for the chosen topic, and an Assessment Type Summary (Assignment / Adventure: assigned, completed, avg performance). The existing task bar chart and trend chart remain here with the existing report-settings sheet.
- **Floating Numbers** are reported as marks earned out of marks available with a completion bar and "correctly constructed n / m elements". No Pass / Fail / Failed wording anywhere in Reports.
- Clicking a topic, subtopic or assessment in Class Overview lists the contributing students; picking one switches to Individual Student with that student selected.
