# Offline Academia App

## What you get
- **Download Academia** sits next to Get Started and Log In on the Mathematics, Reimagined page.
- Clicking it opens a picker: **Android, iOS, Windows, MacBook**. Each option shows short install steps for that device, plus one main Install button.
- Once installed, the app opens straight into the student Academia explorer. It has no sign-up and no login, and every visitor uses it as a student.
- Students can search public schools, add a school to their workspace, open Topics, Subtopics and Sessions, and do Practice and Play. All of this works with no internet.
- Marking happens on the device with the existing step-by-step checker. No AI is used.
- YouTube videos need data and show an "Internet needed" note when offline. Videos uploaded to an activity are saved with the download and work offline.
- When the device is back online, scores sync quietly and new public content is downloaded.

## How the download works on each device
- **Android, Windows, MacBook (Chrome or Edge):** a real one-tap install. The app gets its own icon and window, the same way an installed app does.
- **iOS:** Apple doesn't allow one-tap installs from a website. The picker shows the two steps: Share, then Add to Home Screen. After that it opens full-screen like an app.
- App Store, Play Store and Windows-installer versions are a separate later step. Those need store accounts and signing, which this plan doesn't include.

## Testing note
Offline mode only works in the published app. It won't work inside the editor preview.
