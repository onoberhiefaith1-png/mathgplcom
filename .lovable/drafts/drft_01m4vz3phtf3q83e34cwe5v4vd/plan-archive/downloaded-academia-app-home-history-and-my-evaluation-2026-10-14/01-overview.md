# Downloaded Academia app: Home, History and My Evaluation

Only the downloadable, offline Academia app changes. The website Learn pages, teacher screens, Smartboard, marking engine and Game rules stay as they are. No sign-in is needed. Records stay on the device and sync quietly when there is a connection.

## What the learner will see

**Home (after first setup).** The full school picker stops appearing on every launch. Home shows:
- The header, an online/offline badge and a compact current-school switcher
- **Continue learning**: the most recent unfinished Session, with subject, topic, subtopic, marks so far and a Continue button
- **Started** and **Completed** cards with real counts
- **My Evaluation** ring showing earned marks out of possible marks, with a link to the full report
- **Explore subjects** cards for the current school and class, plus Recent learning

**Bottom tabs on phones and a sidebar on desktop:** Home · Learn · History · Evaluation · Schools.

**Learn.** A cleaner School → Class → Subject → Topic → Subtopic → Session browser. It remembers the last class and subject for each school.

**Session page.** Order: title, path, introduction, video, materials, activities, Practice and Play, progress, then next and previous Session. Videos show a message when there is no connection.

**History.** Two tabs, **Started** and **Completed**, newest first, one card per attempt.
- Started cards: Continue, Restart, Remove (asks first, and the attempt can be recovered)
- Completed cards: Review (read-only), Restart

**My Evaluation.** A large ring (for example 98 / 110 = 89.09%), summary cards, a started-vs-completed doughnut, and a drill-down by subject, topic, subtopic and Session. It also has a line chart of the score over time, each Session's repeat history, and factual messages only. A note explains that this is a personal score built from attempts, not an official school grade. With no attempts it says "No graded sessions started yet."

**Schools.** Current school, My schools, search public schools, add or switch. Changing schools never erases history.

## Scoring rules (from your brief)
- Opening a Session, scrolling or watching its video does **not** start an attempt.
- The attempt starts on the **first mathematical input** in Practice or Play. One attempt per start, never duplicates.
- Each Session attempt is worth **10 marks**. Its activities' marks are scaled together into those 10 marks, not 10 each.
- Continue reuses the same attempt and adds no marks. Restart makes a **new** attempt and adds 10 possible marks. Earlier attempts are kept.
- Restarting one Game does not create a new Session attempt.
- Removing an unfinished attempt takes its earned and possible marks out. Completed attempts can never be removed.
- An attempt is **Completed** only when every activity in the Session has been finished.
- Score = earned ÷ possible across active attempts × 100. Earned marks never go above the maximum, and the same marking event is never counted twice.
