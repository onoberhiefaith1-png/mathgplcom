# Game Pro goes to the Archive, and Imagine becomes Game

## What changes for people
- **The 3D Game is renamed "Game Pro" and archived.** It no longer appears anywhere for teachers, students or schools. Nothing is deleted: its games, rooms, rewards and records all stay as they are.
- **Only you (admin) can open Game Pro.** It is listed in the admin **Application Archive** with Restore/Archive, plus an **Open Game Pro** link so you can look things up and collect data.
- **Imagine is now called "Game".** The word "Imagine" is removed from every screen. The Game button on the dashboard, the class Games list, student Games, Academia activities and the games gallery all open the light 2D Game.
- **Old links still work.** Any old Game link (play, build or gallery) opens the same game in the new Game, because both use the same game data.
