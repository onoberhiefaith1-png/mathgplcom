# Game completion scenes and Academia progression

## Goal
Every completed Game question pauses on a polished result scene before the student can continue. The scene uses the **same Game background**, counts the rewards earned in that question, lights three stars in sequence, and plays that Game’s own cut-out Flow character. Nothing advances until the student presses **Continue**.

The existing Smartboard Flow remains unchanged. Game Flow is a separate, Game-owned setup designed specifically for result scenes: no tray, no trail, no lesson-note emotion controls.

## Five character moments
Each Game can prepare five timeline ranges from its uploaded character video:

1. **Question Complete** — the normal celebration between questions.
2. **Perfect Run** — all marks plus every available timed/reward objective.
3. **Final Victory** — the last question completes the whole Game.
4. **Time Up** — the timer ends with no life available.
5. **Left Early** — the student confirms leaving before the current question is complete.

Perfect Run and Final Victory override the ordinary completion scene when their conditions apply. Missing optional character footage never blocks the result page or Continue.

## What the student sees
- The Game freezes on completion; grading, rewards, time and marks are snapshotted once.
- Three stars illuminate one by one for a completed question, followed by **Complete**.
- A clean reward ledger counts in: completion coin, marks, Vault reward, time earned, lives gained or spent, and any other reward activated during that question. Zero-value rows stay hidden.
- The configured character plays over the original Game background in its saved position.
- **Continue** opens the next question only after the celebration. The final scene changes the action to **Finish**; failure offers **Try again** and **Exit**.
- Reward sounds remain optional and can never delay grading, the page, or Continue.

## Academia behavior
- **Play** uses the attached Game’s own completion design and character. Different activities in one Session can therefore show different backgrounds, rewards and characters.
- Continue opens the next Session activity in its saved order and uses that next activity’s attached Game. The last activity returns to a Session result.
- **Practice** gets a calm, non-game result panel: score, correct lines, working time, progress through the Session, Try again, Back to Session and Continue. It has no stars, Flow character or Game rewards.
- Signed-in Academia, Session guest links and the installed offline Academia app follow the same explicit Continue gate. Uploaded character media is included in the offline pack; linked streaming video still requires data.
