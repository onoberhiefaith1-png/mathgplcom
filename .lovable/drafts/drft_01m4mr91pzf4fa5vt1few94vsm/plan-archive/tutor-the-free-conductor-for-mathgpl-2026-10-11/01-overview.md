# Tutor: the free conductor for MathGPL

**Name:** "Tutor" (shown as **MathGPL Tutor**). It replaces the "Aura Lite" name everywhere. Aura stays archived and unchanged.

## What it is (and the honest limit)
Tutor is a **conductor, not a mathematician**. It never writes mathematics itself. It understands a request, fills in the forms, presses the buttons that already exist, and speaks. The real work is still done by:
- **MathGPL Copilot**: creates lesson notes (uses credits, as it does today)
- **AI Edit**: changes notes and tables (uses credits, as it does today)
- **Floating Numbers + Smartboard**: lay out and mark the mathematics (free)

Tutor itself runs on the phone or laptop with no AI, so it **costs nothing and works offline**.

**What it can do:**
- Recognise commands from a fixed list, including a large list of phrasings, names of classes and notes, and numbers ("delete floating number 5").
- Ask a follow-up question when something is missing ("Which class?").
- Run several steps in a row and check each step before the next one.
- Play a solution that is already stored, one Floating Number at a time, while speaking.

**What it cannot do (because it is free):**
- It cannot understand open-ended wording it has never seen. In that case it shows suggestion buttons.
- It cannot invent a new example or explanation by itself. It asks Copilot or AI Edit to do that, which costs credits and needs internet.
- It cannot explain an answer that isn't already stored. Its spoken lines come from the solution's own steps and teaching notes.

## The five abilities
1. **Create a note by conversation.** "Create a lesson note on set notation" opens Create Note and fills in topic, subtopic and class. If something is missing, Tutor asks for it ("any subtopic" means Tutor picks a standard one). Tutor then hands the request to Copilot, passes on extra requests ("add a Venn diagram example"), and presses Proceed when you say "proceed".
2. **Edit by conversation.** "Make example 2 simpler" or "remove this part" sends exact instructions to AI Edit on the section that is open. Tutor then reads out what changed.
3. **Floating Numbers by voice.** Generate (through the existing button), delete number N, reorder, keep "=" and the fraction together, merge items. These use the existing Floating Number functions. No AI is needed apart from Generate.
4. **Smartboard guide.** Tutor plays a stored solution such as x + 5 = 16. Each step activates the right Floating Numbers in order, the Smartboard places them itself, and the voice explains as each line appears. The sensor stays off while Tutor is driving. You can pause, go to the next step or replay.
5. **Academia guide, offline.** Split screen: Tutor demonstrates on one side while the student works on the other. Tutor checks the student's line with the existing free marking. When a line is wrong, it names the step and explains it out loud. This is saved in the offline download, so it works without data.

## Offline voice
- Speech uses the phone's own voice, which works offline on iPhone and Android.
- Listening works offline on Chrome for Android and recent iPhones when available. Otherwise the student taps or types.
- Questions such as "what is the next step?" or "why minus 5?" are answered from the stored steps and notes, without data.
- Teacher actions taken offline are saved in a queue and sent when the device is back online. You see each one before it is sent.
