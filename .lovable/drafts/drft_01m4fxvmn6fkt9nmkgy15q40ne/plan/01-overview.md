## Smartboard Geometry Properties: tap several sides to find shared properties

**1. Remove the tags under each property**
Each property card keeps its title (for example "Pythagoras theorem") and its equation (CA² = BC² + AB²). The small coloured tags below it (AC, BC, AB) go away.

**2. Tapping several parts adds them together**
- Tap AC: AC is highlighted, and you see every property that uses AC.
- Then tap BC: AC stays highlighted and BC is added. You now see only the properties that use **both** AC and BC.
- Then tap AB: you see only the properties that use AC, BC **and** AB.
- Tap a part that's already selected to unselect it.
- If no property uses all the selected parts, the list shows "No property connects these parts" and nothing else.

**3. Reset button**
At the top of the panel, where it says "Segment", the selected parts appear as a list (AC · BC · AB) next to a **Reset** button. Pressing Reset clears every selected part and every highlight, so you can start again.

**Where this applies:** the teacher's Smartboard test, the full-screen relationships page, and the Properties panel beside each diagram on the Smartboard, which is what students use. Diagrams can be tapped in every section. Everything else stays locked, as it is now. Writing still works only under Solution.

Tapping a property card still lights up the parts it uses.
