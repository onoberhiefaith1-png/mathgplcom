# Classroom-style Geometry Properties

## Goal
Geometry Properties will show the relationship exactly as classroom mathematics. A Pythagoras statement built from the diagram will appear as **BC² = AB² + CA²**, with the selected diagram references and true superscripts—not storage commands, braces, carets, or backslashes.

## What will change
- Keep the formula structurally editable while displaying only finished mathematical notation.
- Use the same structural maths editor when editing a saved relationship, instead of exposing its stored text in an ordinary input.
- Make the saved-property list, student Geometry guide, pathway, and Smartboard all use the same safe classroom renderer.
- Preserve the links between AB, CA, BC and their actual diagram parts, including their colours and highlighting.
- Add regression checks for a Pythagoras relationship and for geometry-reference formulas, so raw syntax cannot reappear.

## Scope
This is limited to Geometry Map property authoring and display. It does not change the diagram, theorem generation, or the stored links to diagram objects.
