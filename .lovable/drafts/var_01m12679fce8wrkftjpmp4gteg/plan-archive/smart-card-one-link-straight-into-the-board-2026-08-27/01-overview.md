# Smart Card: one link, straight into the board

Four focused changes. Nothing about the question, solution, marking, video or teacher workflow changes.

1. **Remove Share Smart Card completely** — the button and the whole share dialog (WhatsApp, Facebook, X, Telegram, LinkedIn, Instagram caption) go away. No replacement.
2. **Copy Smart Card copies only the URL, reliably** — today it calls the clipboard directly and silently does nothing when the browser blocks it (the "Copy failed" behaviour you saw elsewhere). It gets a fallback copy path plus a clear "Link copied" confirmation.
3. **Start Challenge opens the board immediately** — the "Welcome / Continue as Guest / Sign in to Smartboard" screen that appears after Start Challenge is removed. A guest identity is created automatically, so the next thing the visitor sees is the Smart Board with the teacher's challenge loaded.
4. **Back returns to the Smart Card** — only for this public entry path. Normal students keep their existing Assignment Dashboard behaviour.

Already correct today, so untouched: the public link uses mathgpl.com, `/c/<slug>` needs no login, the board is the existing student Smart Board with the teacher's pre-created solution, and AI usage in marking is already charged to the card owner (the teacher), never the guest.
