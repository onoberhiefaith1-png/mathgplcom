# Homepage settings: drop Replace Building, add Building Speed

Two changes, both in the homepage customization area.

## 1. Replace Building is removed

The Settings panel keeps exactly three options, in this order:

1. Change Background
2. Edit MathGPL Building
3. Building Advertisements (owner only, as today)

The Replace Building card, its page and its two routes go away, so nobody can
upload a whole new building or a building video again. Any account that had
previously applied a custom building silently falls back to the original
MathGPL building — the stored custom entry is simply ignored, not deleted, so
nothing is lost if it is ever needed again.

## 2. Building Speed moves into Edit MathGPL Building

Rotation speed already exists in the system but its only control lived on the
Replace Building page. It moves onto the Edit MathGPL Building page as a small
"Building Speed" card at the top:

- a slider from very slow to very fast, with normal speed sitting in the middle
- the live multiplier shown as text (e.g. `0.4x`, `1x`, `2.5x`)
- a Reset to normal button
- speed saves with the same Save action as the artwork, per building version
  (Pro and Free keep their own speed)

Everything else on that page — the slots, Replace Image, Remove Background,
revert, geometry — stays exactly as it is.
