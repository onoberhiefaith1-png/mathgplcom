# Student Workspace: one page, panels on the right, bar pinned to the screen

The student stops leaving their workspace. The list on the left stays where it is, and whatever they pick opens in the space beside it. The four items — Learning, Connections, Courses, Overall View — sit pinned to the bottom of the screen and never move while the page scrolls.

## What changes

1. **No more "Dashboard" entry.** The workspace itself is the home, so that duplicate item is removed from the student's list.
2. **The list on the left opens content beside it.** My Classes, Assignments, Adventure, Courses, My Schools, My Teachers, Requests, Account and Go Live all appear in the main area, with the list still visible. Assignments and Adventure keep behaving exactly as they do now; the rest join them.
3. **Two exceptions.** Building and MathGPL Community still open as their own full experiences. Community keeps a Back control that returns the student to their workspace.
4. **The list no longer slams shut** when the student picks something. It closes only when they close it, and the menu icon is always reachable so it can be reopened.
5. **The four-item bar is fixed to the screen**, like a phone app: it stays put while scrolling, stays visible when the list is open, and the content keeps a little breathing room above it.
6. **Overall View gets shorter** — only Overall Progress, Class Progress and Waiting to be Opened. Go Live and Requests are removed from it, since they already live in the list.
7. **Courses replaces "Skill Builder"** as the name in the list.

Nothing is deleted: every existing page, link and route still works if opened directly. Only where things appear changes.
