# MathGPL Knowledge Base

Immutable reference repository for MathGPL AI generation (lesson notes, smartboard, worksheets, assessments, AI solutions, rendering validation).

## Folders
- Mathematical Rendering Standard
- Solution Generation Standard
- Benchmark Library — immutable benchmark worked solutions. Do not edit, rewrite, reorder, simplify, compress, or reformat.
- Lesson Note Standards
- Smartboard Standards
- Validation Standards

## Usage rule
All generators must compare their output against the relevant Benchmark Library document before display. Benchmarks are training references, not student-facing examples.
