SESSION 6.1.1: READING AND REPRESENTING INEQUALITIES
VIDEO EXAMPLE QUESTIONS

1. Read x < 4 in words.

A. x is greater than 4.
B. x is less than 4.
C. x is at least 4.
D. x is at most 4.

Correct Answer: B

2. Does x = 3 satisfy x ≥ 3?

A. Yes, because ≥ includes equality.
B. No, because x must be greater than 3.
C. Yes, because 3 is greater than 3.
D. No, because equality is excluded.

Correct Answer: A

Question 4
List the integers satisfying −3 < x ≤ 2.

Solution
The integers must be greater than −3 and less than or equal to 2.

Exclude −3, but include 2.

The integers are −2, −1, 0, 1, 2.

Question 5
Find the largest integer x satisfying 2x < 9 and explain why the real solution set has no greatest member.

Solution
2x < 9

Divide both sides by 2:
x < 9/2
x < 4.5

The largest integer less than 4.5 is 4.

For any real solution x < 4.5, choose the midpoint:
y = (x + 4.5)/2.

Then x < y < 4.5.

There is always a larger real solution, so the real solution set has no greatest member.
