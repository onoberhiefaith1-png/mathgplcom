# Material sources for the New Surfaces collection

- `silk-satin_*`: Poly Haven, **Crepe Satin** — https://polyhaven.com/a/crepe_satin
  - License: CC0 — https://polyhaven.com/license
  - Downloaded as the 1K JPG diffuse, OpenGL normal, and roughness maps.
  - The roughness map is also used as a neutral AO fallback because the source set does not publish a separate AO map.

The existing PBR scans in this folder are unchanged and continue to power the original writing surfaces.
